# 🧮 MathLab AI

**Mathematics × Computing**

MathLab AI est une plateforme interactive dédiée à l'exploration
des mathématiques à travers Python, le calcul scientifique,
la visualisation et l'intelligence artificielle.

## Version actuelle

**v0.1.0 — Initialisation du projet**

## Technologies

- Python
- Streamlit
- SymPy
- NumPy
- SciPy
- Pandas
- Plotly
- Pytest
